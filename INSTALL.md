# Installation

The public patcher is still being packaged and verified.

When released, users will need:

1. A legally obtained original Android APK of *Gloria Union*.
2. The v0.25 English patch package from this repository's Releases page.
3. The included patching instructions for Windows.

Do not download APKs offered by unrelated third parties. Back up existing saves
or the emulator instance before replacing an installed build.

Exact commands and original-file checksum requirements will be added alongside
the verified patcher.
