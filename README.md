# Gloria Union English Fan Translation

An unofficial English fan-translation project for the Android version of
*Gloria Union*.

Version 0.25 makes the main story playable and understandable in English. The
dialogue boxes carry the complete narrative, while most essential menus, battle
instructions, cards, requirements, items, equipment information, and result
screens have also been localized.

## Release status

The verified v0.25 patch package is distributed through this repository's GitHub
Releases page. A complete modified game APK is not stored in the repository or
release. Players must supply the exact supported original APK when applying the
translation patch.
